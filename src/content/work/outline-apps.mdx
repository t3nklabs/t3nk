Outline makes it easy for anyone to run their own VPN. **Outline Manager** is a GUI that stands up a Shadowsocks server on any cloud host in a few clicks; **Outline Client** is a cross-platform proxy app — Windows, macOS, Linux, iOS, Android, ChromeOS — that connects to any Shadowsocks server and lets you share access with the people who need it.

The mission is access: give censored or throttled networks a dependable door to the free and open internet. Source, docs and issues live on [GitHub](https://github.com/OutlineFoundation/outline-apps).
