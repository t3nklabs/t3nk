The T3NK site is now a static build. The old Vue single-page app is gone; the whole site is pre-rendered Astro with zero framework JS on the wire.

What changed:

- **/work is now a tag-driven feed.** Projects and updates live in one markdown collection, sliced by tags — `TOOL`, `AI/ML`, `WEB3`, `PRIVACY` and kind tabs `PROJECTS` / `UPDATES`.
- **Every project has its own page** at `/work/<slug>`, with its updates linked underneath.
- **Built by GitHub Pages** on every push to `main`.

Adding a project or an update is now just a markdown file in `src/content/work/`.
