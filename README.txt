T3NK — Capital + Code

This repo is the source of our website: https://t3nk.com

T3NK is the engineering-first VC. We invest in early-stage software companies,
then our engineers join the repo and help them ship.

Static site built with Astro, deployed to GitHub Pages on every push to main.

    npm install
    npm run dev      # local dev server
    npm run build    # static build into dist/
